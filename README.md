# Yukibana

This repository holds Yukibana Light, the browser IDE with its language
packs and the wasm Swift toolchain, in `light/`. How to build, run and
deploy it is `light/README.md`.

The cloud registry (the SvelteKit Worker, the Supabase schema, the CLI, the
GitHub Action and the desktop demo) used to live here as well. It has been
removed; its history is in this repository's git log.
