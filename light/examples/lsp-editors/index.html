Language servers in two editors

Each language's server is its pack's server.js, started in a worker as a LanguageSession of @yukibana/runtime. The two pages differ only in the editor that is its client.

  • Monaco: the sample project in Monaco, bound by @yukibana/monaco's MonacoBinding. Squiggles, hover, completion, signature help, go to definition across files, references, rename, code actions, semantic highlighting, inlay hints and the outline, all in Monaco's own UI.
  • Textarea: the entry file in a plain <textarea> (@yukibana/editors/textarea), the page being the session's client: the problems list, the hover at the caret, completion and go to definition, drawn beside it.

The languages are Python, C++, Rust, Go, TypeScript and JavaScript; a page opens with ?language= (python, cpp, rust, go, typescript, javascript). Each needs its pack installed in light/app/static/packs (light/setup).
