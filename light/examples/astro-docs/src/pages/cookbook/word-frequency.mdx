A word is a run of the letters a to z, compared without case. Each
program reads its input line by line until the end, keeps a count per
word, and sorts by count, then by word. The input is the same for all of
them, and you can change it under the code.

Pick a language. Only the tab you open hydrates: a tab that is never
shown loads nothing, not even its language's description.

## What to look for

* **Splitting.** JavaScript and Python find the words with a regular
  expression; C++ walks the characters; Rust and Swift split on every
  character that is not a letter and drop the empty pieces.
* **Ties.** C++'s `std::map` is already in alphabetical order, so a
  *stable* sort by count is enough. The others sort by two keys.
* **Input.** Every program reads until end of input. In the browser that
  is the end of the text in the *Input* box, given line by line.
