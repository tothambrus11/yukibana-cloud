This site is plain, static HTML built by Astro. Every code sample is a
*playground*: it is rendered as highlighted code when the site is built,
and becomes interactive only when you scroll to it. Even then, the
compiler is not fetched until you press **Run**.

## How a page stays light

The page loads no playground code at all. Each playground is an
[Astro island](https://docs.astro.build/en/concepts/islands/) hydrated
with `client:visible`: when it scrolls into view, a few kilobytes of
Preact and Yukibana's core arrive, then its language's description.
The compiler (Yukibana Light's *pack* for the language) is fetched on the
first Run, once per page: two C++ samples share one compiler.
